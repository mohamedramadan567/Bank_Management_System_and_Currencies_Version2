# 💻 Bank Management and Currencies Exchange – C++ Project

This is a console-based banking system built using **C++ and Object-Oriented Programming (OOP)** principles.  
The project simulates a basic banking environment with features like user management, bank transfers, and currency exchange, all with persistent storage via `.txt` files.

---

## 🚀 Features

- ✅ Manage bank accounts: create, update, delete, and search  
- ✅ Currency exchange system between multiple currencies  
- ✅ User management system with roles and permissions  
- ✅ Login activity log for each user  
- ✅ Record and control of bank transfers  
- ✅ Console-based UI (no GUI)  
- ✅ All data is saved and read from text files

---

## 🛠 Tech Stack

- **Language:** C++  
- **Paradigm:** Object-Oriented Programming (OOP)  
- **Storage:** File Handling (`.txt`)  
- **Interface:** Console Application

---

## 🎯 Purpose of the Project

This project was built to apply and demonstrate key OOP concepts such as encapsulation, inheritance, abstraction, and modular design.  
It also serves as a practical application of file handling, access control, and structured code design in C++.
